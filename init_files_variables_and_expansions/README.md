# Init Files, Variables and Expansions - Shell Scripts

> **Folder**: `init_files_variables_and_expansions/`
>
> This folder contains advanced Bash scripts to manipulate environment variables, aliases, arithmetic expansions, and other shell features.

## Script List

| Script                   | Description                                                                |
|--------------------------|----------------------------------------------------------------------------|
| 0-alias                  | Creates a custom alias.                                                    |
| 1-hello_you              | Displays a welcome message with the user's name.                           |
| 2-path                   | Adds `/action` to the PATH environment variable.                           |
| 3-paths                  | Counts the number of paths in the PATH variable.                           |
| 4-global_variables       | Displays all environment variables (`printenv`).                            |
| 5-local_variables        | Displays all local and environment variables (`set`).                       |
| 6-create_local_variable  | Creates a local variable named BEST.                                       |
| 7-create_global_variable | Creates an environment variable named BEST.                                |
| 8-true_knowledge         | Displays the sum of 128 and the TRUEKNOWLEDGE variable.                    |
| 9-divide_and_rule        | Displays the result of dividing POWER by DIVIDE.                           |
| 10-love_exponent_breath  | Displays BREATH raised to the power of LOVE.                               |
| 11-binary_to_decimal     | Converts a binary variable to decimal.                                     |
| 12-combinations          | Displays all two-letter lowercase combinations except "oo".               |
| 13-print_float           | Displays a NUM variable as a float with two decimals.                      |
| 14-decimal_to_hexadecimal| Converts a decimal variable to hexadecimal.                                |

## Usage

Each script is executable and can be run directly from the terminal:

```bash
./script_name
```

Give execution rights if needed:

```bash
chmod +x script_name
```

## Learning Goals

This folder aims to:
- Deepen shell variable management
- Manipulate aliases and expansions
- Automate advanced tasks in Bash
